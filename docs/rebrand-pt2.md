# Rebrand pt2

Branch: `rebrand-pt2`. The prior live workspace and gallery are saved on `ReBrand`
at checkpoint `f05c753` before this design begins.

IronRoot Solutions keeps its name and shifts to a graphite/electric-blue visual
identity. The circuit-tree mark, typography, workshop-photo hero, navigation,
service presentation, public pages, gallery, and authenticated print workspace
share the new palette. No stock or generated product photos are introduced.

The home page gives visitors two clear paths:

- 3D printing: explore the gallery, discuss a project, or open the print studio.
- Technology work: web applications and software design, hardware diagnostics and
  repair, and security-camera, device, and network setup.

The service page has four categories. Security-service links preselect the
security topic in the contact page; software design is also a contact option.
Contact prepares an email draft addressed to ironrootsolutions@gmail.com, with
Facebook retained as another option. Preparing a brief does not send it.

The local production preview is `http://127.0.0.1:3002` after `npm run build` and
`npm run preview` in `App/iom-frontend`. This change is not a public deployment.

Validation: frontend interaction tests cover the printing/tech paths, security
inquiry navigation, and the existing account, gallery, and upload flows. The
production build and production server tests check the compiled route/asset
behavior. The in-app browser was unavailable, so a rendered desktop/mobile visual
review remains outstanding.

The homepage hero now follows the octagonal collector display through three
documented stages: printing the base, assembling the enclosure, and arranging
the collectibles. Visitors can select a stage to see the original photo and
plain-language explanations of visible details. This replaces the abstract
layered-cube illustration. No dimensions, materials, or production metrics are
invented.

Motion includes a staggered hero entrance, a brief circuit-line sweep, photo
fades on stage/gallery changes, hover lift and border highlights, button sheen,
navigation underlines, and form-focus feedback. Scroll reveals progressively
enhance browsers supporting CSS view timelines. All animations are finite;
reduced-motion preferences disable them. Hover movement is limited to fine
pointers, and keyboard focus receives equivalent visual emphasis.

The current icon combines a tree silhouette with thick circuit-board traces,
three circular connection pads, and a solid trunk splitting into angular roots.
The enclosing hexagon and the literal I-beam have been removed. The header,
footer, About page, favicon, and web-app manifest share this SVG.

The circuit roots now descend beneath a broken, warm-gray earth contour.
The filled blue bowl and continuous surface line are removed to avoid a water
reading. Downward root tips retain the angular circuit styling and connection pads.
